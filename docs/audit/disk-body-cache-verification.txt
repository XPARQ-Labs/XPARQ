     92 kernel tests, 2 shared payload compatibility/isolation tests,
     4 bounded decoder tests, 1 header-preserving eviction/rehydration test.

The node eviction regression mines a real canonical branch, evicts intermediate
bodies, verifies historical RPC and receipts, complete latest-block results,
header locator and work/difficulty behavior, startup replay and a stronger reorg
that must rehydrate old bodies. It also checks Merkle tampering, wrong height and
trailing bytes, and that a pinned read transaction retains its old canonical tip
while a new branch commits atomically. The storage regression rejects missing
heights and oversized entries without accepting a partial log.

Implementation retains all journals and all canonical bodies on disk. Journal
pruning, scratch-database recovery and a disk-backed active-state store are not
implemented in this stage. The cache budget is for logical block encodings, with
pinned genesis/tip exceptions; it does not establish a whole-process RSS bound.

The final node/network command and resource results are recorded below.
Known pre-existing frozen mainnet identity fixture discrepancies are
not regenerated; devnet regression passes do not resolve those discrepancies.
