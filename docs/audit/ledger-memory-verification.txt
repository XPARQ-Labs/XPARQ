Shared ledger payload verification
==================================

All commands use the pinned Rust 1.99.0 toolchain and --locked. Native
transport commands use the extracted protoc binary via PROTOC and its library
path via LD_LIBRARY_PATH. Local socket tests run with sandbox approval.

Compatibility coverage compares canonical Block, DeployProgram, ProgramRecord
and ProgramRegistry bytes against owned field encodings, decodes legacy bytes,
checks the old owned-input program hash, and tests Arc copy-on-write isolation.
Code size and bounded decoding rules are unchanged. Reorganization and snapshot
regressions verify the existing commit-after-validation behavior.

The known pre-existing frozen mainnet identity fixture discrepancies are not
regenerated or represented as resolved by these devnet tests. The default
workspace compilation passes; the full mainnet test suite is not claimed here.

The measured release resource experiment is recorded separately in
ledger-memory/README.md with machine-readable reports and 200 ms samples.
Full historical ledger storage remains in RAM; sharing does not impose a
constant RSS bound or remove independent decode/serialization allocations.
